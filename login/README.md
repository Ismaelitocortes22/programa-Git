# FARMASOFT React + Bootstrap

Proyecto académico de una farmacia con React, Bootstrap 5, React Router y CSS separado.

## Ejecutar
```bash
npm install
npm run dev
```
Luego abre http://localhost:5173/

## Rutas
- / : página principal
- /login : inicio de sesión
- /dashboard : panel de ejemplo

El login es demostrativo; todavía no usa una base de datos.
